# Notification module (Node demo)

This folder is a **Node/Express sample** of the same HTTP routes.

The **copy-a-folder sellable SKU** is [`../notifications`](../notifications/README.md) (Python 3.11+, no npm, tests included):

```python
from notifications import create_notifications
```

```bash
python -m notifications
```

To run this Express demo:

```bash
npm install
node server.js
# open sample_frontend/index.html
```

Do not copy `node_modules` to a buyer.
